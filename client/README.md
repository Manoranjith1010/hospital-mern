# Client Documentation

## Hospital Management System - Client

React-based client for the Hospital Management System with Redux state management and Tailwind CSS styling.

### Features

- User authentication and authorization
- Patient dashboard
- Doctor discovery and filtering
- Appointment management
- Medical records viewing
- Role-based access control
- Responsive UI components
- Real-time notifications

### Getting Started

```bash
npm install
npm run dev
```

### Build

```bash
npm run build
```

### Project Structure

- `src/api/` - API integration and services
- `src/components/` - Reusable UI components
- `src/features/` - Redux slices for state management
- `src/hooks/` - Custom React hooks
- `src/pages/` - Full page components
- `src/layouts/` - Layout wrappers
- `src/routes/` - React Router configuration
- `src/utils/` - Utility functions
- `src/styles/` - Styling

### Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run preview` - Preview production build
- `npm run lint` - Run ESLint
- `npm run lint:fix` - Fix ESLint errors
